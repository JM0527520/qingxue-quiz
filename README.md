# 青学 团员知识练习

适配电脑和手机的静态刷题网页，收录《团员知识检测题目与答案对照》中的全部136道题。

- 默认做题模式，可切换为直接展示答案的背题模式。
- 随机抽取未浏览题；单选、多选、判断题的选项分别乱序，并保持答案正确对应。
- 单选35题、多选32题、判断25题、填空30题、简答14题。
- 单选、判断、多选、填空每题1分；多选必须选全且不多选。
- 填空逐字匹配原文，每空的标点、括号、数字和空格均须一致，全部填对才得分。
- 简答题独立思考后查看参考答案，不自动判分。
- 学习记录和简答草稿保存在当前浏览器，两种模式分别记录。不同设备之间不自动同步。

## 使用

开启 GitHub Pages 后，访问仓库设置中显示的网址即可。也可以下载 `index.html`，用支持网页脚本的浏览器离线打开。

答案按源文档收录。网站没有后端服务，不收集或上传用户的答题记录。
